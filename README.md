# HytaleXP - Mods de Progression

Ce dépôt contient plusieurs mods de progression pour Hytale.

## 📁 Mods Disponibles

### OnePieceXP
Un système complet de progression et de statistiques inspiré de l'univers One Piece.

**Caractéristiques principales :**
- 60 niveaux répartis en 3 zones marines (East Blue, Paradise, New World)
- 6 statistiques : Vitalité, Résistance, Attaque, Stamina, Haki, Respiration
- Système de points (5 libres + 1 auto par stat par niveau)
- Gap de 400 points pour l'endgame
- Interface UI complète

👉 [Voir la documentation complète](OnePieceXP/README.md)
👉 [Guide de démarrage rapide](OnePieceXP/QUICKSTART.md)
👉 [Guide développeur](OnePieceXP/DEVELOPER_GUIDE.md)

### Nouveau dossier (VKCraft)
Mod Hytale original avec système de stats, perks et quêtes.
